# Морской бой — Дамир и Даня

[Открыть игру](https://ivantimurov13-design.github.io/morskoy-boy/)

Морская игра на русском: против компьютера, для двоих на одном устройстве или по сети каждый на своём. Три режима: обучение на поле 8×8, классический бой и секретный радар. Ручная и случайная расстановка, эффекты, звук, награды и сохранение партии.

## На iPad

1. Открой ссылку в Safari.
2. Нажми **Поделиться → На экран Домой → Добавить**. Если есть переключатель **Открывать как веб-приложение**, включи его.
3. Запусти игру с новой иконки один раз с интернетом. В окне **На iPad** появится сообщение о готовности к работе без интернета.

**Mac для опубликованной игры не нужен.** Для первого открытия и обновлений требуется интернет. Против компьютера и вдвоём на одном устройстве можно играть без сети после загрузки; если iPad очистит данные сайта, понадобится загрузить игру снова. Награды и локальные партии остаются в конкретном браузере. Сетевой бой синхронизируется через сервер и требует интернета у обоих игроков.

## Друг против друга по сети

1. Откройте игру каждый на своём устройстве и выберите **По сети**.
2. Один капитан выбирает режим и нажимает **Играть по сети → Создать комнату**.
3. Второй нажимает **Играть по сети**, вводит код и выбирает **Присоединиться**.
4. Каждый расставляет свой флот и нажимает **Флот готов!**

Mac может быть выключен. Можно играть из разных сетей. При потере связи партия сохраняется: вернитесь в игру в том же браузере и нажмите **Вернуться в сетевой бой**. Комната хранится 24 часа после последнего игрового действия. После победы оба могут нажать **Ещё один бой** для реванша.

[Устройство сервиса и откат](multiplayer/README.md).

## На Mac локально

Дважды нажми **Играть.command** или выполни `npm install`, `npm run build`, `npm start`. Открой `http://localhost:4173`. Локальный запуск через Wi-Fi по-прежнему требует включённого Mac; для независимого запуска используй опубликованную ссылку.

## Разработка и публикация

Node.js 22.12+ (или 20.19+).

```sh
npm ci
npm run dev
npm test
npm run build
npm run build:pages
npm run deploy
```

- `dist` — локальная сборка с базовым путём `/`.
- `site-dist` — GitHub Pages-сборка с базовым путём `/morskoy-boy/`.
- `main` — исходный код; `gh-pages` — только готовые файлы сайта.
- `npm run deploy` требует Git и авторизованный GitHub CLI с доступом к репозиторию. Команда собирает сайт и публикует его в `gh-pages`; GitHub Pages раздаёт корень этой ветки.
- Service Worker кеширует только файлы этой игры и не удаляет кеши других сайтов или игр на том же домене.
- После обновления файлов обнови страницу, чтобы открыть новую версию. Текущая партия хранится отдельно от кеша приложения.

Нет аккаунтов, рекламы, встроенной аналитики и внешних шрифтов. Звук работает через Web Audio и отключается кнопкой. Все изображения включены в сайт. Иллюстрации созданы с помощью imagegen.

Инструкции: [Apple — добавить сайт на экран «Домой»](https://support.apple.com/guide/ipad/ipad8f1f7a29/ipados), [GitHub Pages](https://docs.github.com/en/pages).
